# DaSong Studio

DaSong is an elegant, high-end lyrics and chord library styled like professional studio DAW hardware, complete with custom key transposition, automatic responsive scrolling, and collaborative digital teleprompters.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Configure environment variables in `.env` (see `.env.example`)
3. Run the app:
   `npm run dev`
